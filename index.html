MANAJEMEN DATA MASSAL

Import Data Buku dari CSV

Masukkan koleksi dari Excel melalui berkas CSV.

Unggah berkas CSV

Format .csv dengan baris pertama sebagai header.

Format kolom CSV

Gunakan nama header berikut. Header tidak peka huruf besar/kecil; beberapa variasi nama Indonesia/Inggris juga dikenali.

judul,pengarang,penerbit,tahun,isbn,sub-disiplin,stok,lokasi-rak
"Biologi Laut","A. Penulis","Penerbit X",2022,9780000000000,"Ekologi Laut",5,"A-01"
  • Ekspor lembar Excel menjadi CSV UTF-8 (Comma delimited).
  • Kolom judul wajib diisi; stok kosong akan dianggap 0.
  • Gunakan tanda kutip untuk teks yang mengandung koma.
  • Data disimpan di localStorage browser, bukan server bersama.
